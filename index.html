    04 • PROJECT

    AgriSense

    Machine Learning Based Crop Growth, Pest Risk Prediction and Smart Agricultural Advisory System.

    Designed as a PBL Machine Learning prototype for Chennai Institute of Technology. The image branch uses a public PlantVillage-trained EfficientNetV2S model; the field-risk branch uses the supplied demo dataset. The two outputs are combined as decision fusion, not claimed as a separately trained multimodal neural network.
